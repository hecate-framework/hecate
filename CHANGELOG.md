# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/) with lockstep versions across all packages
(see [ADR 0005](docs/adr/0005-single-brand-monorepo-lockstep-versioning.md)).

Each release heading states the supported Lua version.

## [Unreleased] — Lua 5.5

### Fixed

- `hecate.doc`: the `#` anchor of a heading 2 sits next to its text instead of above it (it ignored the padding of the heading), and the "Edit this page" link of a generated reference page opens the Lua file that holds its documentation comments (new front matter `source` and site setting `source_edit_link`) instead of a Markdown file that does not exist in the repository.

- `hecate.net`: `BufferedReader:read_until` no longer raises `ProtocolError` for a record exactly at the limit when a multi-byte delimiter arrives split across reads (found by the new property test); `TlsError` carries `context.reason`; `Stream` declares `shutdown` and `is_closed`, `BufferedWriter` gets `is_closed`; tests added: chunking properties of the reader (random splits against an unsplit baseline), a peer writing one byte at a time, IP SAN identity, an expired certificate, an ALPN mismatch, cancelling a stalled handshake, and a handle-leak check around every TLS test; fixtures for the expired certificate; `.gitattributes` keeps certificates and keys LF.

- `hecate.net` review fixes (TLS and buffered reader): `TlsStream` serialises drain and write under a mutex (records can no longer be reordered by a concurrent reader and writer), `is_closed` follows a cancelled write, a stalled session raises instead of spinning, `read` validates `max` and the native `read` clamps it to 16 KiB; `connect_tls` and `tls.connect`/`accept` validate arguments before connecting, reject inconsistent options (`tls_config` with `ca_pem`, `cert_pem` without `key_pem`) and name the missing `ca_pem` (OQ-41); `BufferedReader` validates the per-call limit, accepts a `limit` on `read_exact`, joins chunks once per read (linear instead of quadratic) and raises on a read after `close`; the native crate forbids `unsafe`, denies warnings and clippy, and drops the rustls `logging` feature (the `log` crate leaves `Cargo.lock`).
- `hecate.net`, `hecate.reactor`: `net.resolve` never returns an empty list (it raises `TransportError`), `connect`, `listen` and `bind_udp` validate the port before resolving, `pipe_listen` and `pipe_connect` raise `ArgumentError` for a Unix socket path longer than the platform limit, `Reactor:live_tasks` is renamed `live_coroutines` (glossary), glossary entries stream, back-pressure and half-close.

- `hecate.net` and `hecate.reactor` review round (nine reviewers, all findings addressed): `TlsStream` serialises `write` and `shutdown` under one mutex and closes the stream when a write or shutdown fails or is cancelled after the session accepted bytes (no leaked prefix, no interleaved concurrent writes); a reader is no longer held up by a writer blocked in back-pressure; cancellation is never swallowed; a closed `TlsStream`, `BufferedReader` or `BufferedWriter` raises `reactor.TransportError` (`EBADF`, stable `context.operation`) like `TcpStream`; a second concurrent reader, and a write after `shutdown` (`EPIPE`), raise; the native module no longer fails the end of the transport with "received plaintext buffer full" (rustls 0.23.46, found by reading its source); native TLS errors carry a kind taken from the `rustls::Error` variant (`context.reason`), ALPN names are validated, `Session` and `Config` have `close`/`__close`, native `read` reuses a scratch buffer and `write` takes an offset; `reactor.spawn` options `stdout`/`stderr = "ignore"` now take effect (the stdio table was built with an `and nil or` trap); the message pipe marker and descriptor no longer leak into grandchildren; message pipe frames with a stream attached to a frame that announces none, several streams on one frame, or a malformed or oversized frame raise `TransportError` `EPROTO` and close the peer; `Process:kill` treats `ESRCH` as success and validates the signal; Windows environment names merge case-insensitively; `TcpListener:accept` skips a connection whose peer already reset it; `keepalive_delay` must be a positive integer; "task" becomes "coroutine" and "channel" becomes "message pipe" in messages and docs.
- `hecate.net` option and error ergonomics: TLS options are validated against per-function allow-lists (`client_config`, `server_config`, `connect_tls`, `tls.connect`, `tls.accept`), so `verify = false` or `ca_pem` on a server raises `ArgumentError` naming the kind of option; `alpn` is validated in Lua; `net.connect` and `net.listen` validate options before resolving and their failures name the endpoint (`connect to h:p failed: ECONNREFUSED connection refused (tried ...)`, `context.host`, `context.port`, `cause`); DNS failures carry `context.host`; `connect_tls` validates before building the configuration and caches the default client configuration per ALPN list; the unknown-issuer hint is keyed on `context.reason`; `UdpSocket:send_to` accepts numeric addresses only (the error points to `net.resolve`); `TlsStream:server_name()` is now `requested_server_name()`; `net.TransportError` re-exports `reactor.TransportError`; `write`, `shutdown` and `send_to` return nothing.
- `hecate.doc`: the reference generator no longer crashes or renames members when a class has undocumented bare fields (the result depended on hash order); `tools`: `check-links` ignores links into a code reference that is not generated.

### Added

- Website: French translation of the home page, the how-to guides, the explanation pages, the reference index and the glossary (13 pages), with the French terminology decisions in `website/fr/glossary-terms.md` (kept out of the built site).
- Website: how-to guides (TCP, TLS, deadlines and cancellation, UDP, pipes and DNS, child processes and message pipes), explanation pages (transport model, TLS trust and security defaults, multi-process serving), section landing pages, the public glossary resynchronised with `docs/glossary.md`; `tools`: `check-docs-examples` (website code blocks match their tested example files); `hecate.net` and `hecate.reactor`: ten new tested examples.
- `hecate.reactor`: the multi-process primitives of ADR 0023: `reactor.spawn` (a long-lived `Process` with `wait`, `kill`, environment, working directory, inherited or ignored output), `reactor.ipc` (a framed message channel between parent and child, `Peer:send(message, stream?)` and `Peer:receive()` with TCP stream hand-over, `ipc.parent()` in the child; messages are strings of at most 16 MiB) and the `reuseport` option of `tcp_listen` with the `reactor.supports_reuseport()` probe (`ENOTSUP` without luv support, OQ-43).

- `security.yml`: `cargo audit` and `cargo deny` for the Rust crates of the native modules (PR touching a Cargo manifest or lockfile, push to main, weekly), policy in `deny.toml` (permissive licences only, so that Hecate stays MIT; crates.io only; build targets restricted to the three platforms), tools built from source at pinned versions; Dependabot watches the Rust crates (weekly, one grouped pull request); the cache actions of `ci.yml` are on the same version; `main` merged into the branch (Dependabot's action bumps).
- `hecate.net`, `hecate.reactor` (owner decisions of 2026-10-18 on the net review): `UdpSocket:send_to` now takes `(host, port, data)`, the destination first like `connect` (changed, was `(data, host, port)`); `net.bind_udp(host, port, { family })`; a failed `net.connect` reports every attempt in `context.attempts`; the server-side TLS idiom is documented as the two-step `tls.accept(listener:accept(), config)` (fork the handshake per connection); unit tests of the native crate (`cargo test` runs in CI); the timing-dependent reactor and net tests wait on channels and yields instead of sleeps and elapsed-time bounds.
- ADR 0023 (multi-process serving) and ADR 0024 (TLS trust store, security reviewed) accepted by the owner on 2026-10-18; OQ-8, OQ-41 and OQ-44 resolved; the GC spike now includes an ORM-shaped workload (generational mode: typical slow step 2 to 3 times shorter, rare major collection 0.25 to 0.8 s); `rustls` updated to 0.23.46 (four advisories of 0.23.45, `cargo audit` clean); key elements of the upstream luv issue for TCP `reuseport` ([OQ-43](docs/spikes/OQ-8/luv-issue.md)).
- `hecate.net`: TLS trusts the operating system's store by default (`rustls-platform-verifier`, Accepted [ADR 0024](docs/adr/0024-tls-trust-store.md), owner decisions of 2026-10-18): `net.connect_tls(host, port)` works against a public server with no option, `ca_pem` adds trust anchors, `system_roots = false` trusts only `ca_pem`, verification still cannot be disabled, an unknown issuer says how to fix the trust store; 4 to 7 crates added per platform; a public-server test (`HECATE_NETWORK_TESTS=1`) runs in CI. Garbage collector mode: spike and OQ-44 ([report](docs/spikes/OQ-44-gc-mode.md)); OQ-43 updated with the upstream research.
- Multi-process serving (OQ-8): spike with measurements on Linux and, from CI, on macOS and Windows ([report](docs/spikes/OQ-8-multi-process.md), `docs/spikes/OQ-8/`), Proposed [ADR 0023](docs/adr/0023-multi-process-serving.md) (share-nothing workers; `reactor` mechanism, `kernel` policy; listening strategies `reuseport` on Linux and `round_robin` elsewhere, a shared listening socket measured and dropped; Linux never constrained by another platform), OQ-43 (TCP `SO_REUSEPORT` from Lua: luv sets it for UDP only, a four-line patch is verified), glossary entries primary, worker and listening strategy, the "Workers" section of concurrency.md, roadmap item for the `reactor` primitives.
- `hecate.net` review fixes: native TLS session failures always raise `TlsError`; `TlsStream:is_closed()` reflects a closed inner stream; a handshake that makes no progress raises instead of spinning; a closed `BufferedReader` raises instead of reporting a clean end of stream; `limit` and `max` arguments are validated; a poisoned `BufferedWriter` raises a fresh `NetworkError` with the original failure as `cause`. CI sets `HECATE_REQUIRE_TLS=1` so the TLS tests cannot be skipped silently.

Task `build-native` builds the module into `.hecate/rocks`. Loopback tests against a local test CA skip with a message when the module is not built.

- `hecate.net` (step 5): `PipeStream`, `PipeListener`, `net.connect_pipe` and `net.listen_pipe` over Unix-domain sockets (named pipes on Windows); `hecate.reactor`: `pipe_connect`, `pipe_listen`, `PipeStream`, `PipeListener`, reusing the TCP stream machinery. TLS remains.
- `hecate.net` (step 4): `UdpSocket` (`send_to`, `receive_from`, `local_address`, `close`) and `net.bind_udp` with host-name resolution; `hecate.reactor`: `udp_bind` and `UdpSocket`, suspending datagram I/O. - `hecate.net` (step 3 of the roadmap item): `TcpStream` (implements `Stream`; `shutdown`, addresses, options, `reader()`/`writer()`), `TcpListener`, `net.connect` and `net.listen` with host-name resolution, over the reactor transport; per-operation deadlines through `reactor.deadline`. `hecate.reactor`: `resolve(host, options?)`, a suspending `getaddrinfo`. Design choices in OQ-32. Failures of TCP and name resolution raise `reactor.TransportError`, a `core.NetworkError` (`catch` on `NetworkError` works; `IoError` stays for fs and processes).
- `hecate.net` (step 1 of the roadmap item; not complete): `BufferedReader` (`read_line`, `read_until`, `read_exact`, `read_some`, limit on record length) and `BufferedWriter` (`write`, `flush`, capacity, poisoned after a failed flush) over any object implementing the `Stream` interface, and `EndOfStreamError`. - `hecate.reactor` (transport step, OQ-28 option a): `tcp_connect`, `tcp_listen`, `TcpStream` (`read`, `write`, `shutdown`, `close`, `peer_address`, `local_address`, `set_nodelay`, `set_keepalive`, `<close>`-able) and `TcpListener` (`accept`, `close`, `local_address`) as suspending calls, so `hecate.net` never requires luv. Cancellation closes or abandons safely without leaking handles or callbacks; failures raise `IoError` with `context.errno`. Every real-clock run now guards against `SIGPIPE`. Numeric addresses only; UDP, DNS and pipes remain. Design questions are recorded in OQ-30 and OQ-31; OQ-28 is resolved.
- `hecate.reactor` (step 4 of the roadmap item): `detach`, `fs` (`read_file`, `write_file`, `stat`, `remove`, `mkdir`, `rmdir`, `list`), `wait_signal` and `run_process` as suspending calls over libuv, and `IoError`. They need the real clock. Design questions are recorded in OQ-26. `offload`, worker primitives and the website reference remain.
- `hecate.reactor` (step 2 of the roadmap item): `Channel(capacity)` (rendezvous or buffered, FIFO, `close`), `ChannelOperation` (`Channel:send_op`, `Channel:receive_op`) accepted by `select` next to futures, `Semaphore`, `Mutex`, `Monitor` and `Condition` with `<close>`-able `Permit`s. All are cancellation-safe (cancelled waiters are withdrawn and never swallow a permit, value or signal) and FIFO fair. `ClosedChannelError` is new in `hecate.core`. Design questions are recorded in OQ-25.
- `hecate.reactor` (Phase 1, step 1 of the roadmap item; not complete): the `Reactor` scheduler over luv with a real clock and a deterministic virtual clock, `Future` (`value`, `cancel`, `done`, `state`), `fork`, `join`, `select`, `sleep`, `scope` and `deadline` with structured concurrency and cooperative, level-triggered cancellation that runs `<close>` handlers, `Instant`, deadlock detection, and `NonYieldableContextError` (new in `hecate.core`) for suspending calls outside a managed coroutine or inside a non-yieldable C boundary. The test task now puts every package source tree on the path so packages can require their dependencies. Design questions OQ-22 to OQ-24 are recorded. Channels, synchronisation primitives, `detach`, `offload`, signals, processes and file-system operations remain.
- `hecate.core` (Phase 1): `class`, `trait`, `interface`, `finalise` (single inheritance, flat trait composition with exclusion and aliasing, conformance checked at finalisation, inherited metamethods including `__close`), introspection (`name`, `superclass`, `traits`, `interfaces`, `is_instance_of`, `implements`, `origin`), the `Error` hierarchy with cause chaining, stable codes and optional tracebacks, `enumeration`, `value_class` and `hecate.core.compat`. The `fallback_provides` class option declares the members an `__index` fallback provides. Design questions OQ-19 to OQ-21 are resolved.
