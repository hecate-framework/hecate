# Changelog

All notable changes are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/) with lockstep versions across all packages
(see [ADR 0005](docs/adr/0005-single-brand-monorepo-lockstep-versioning.md)).

Each release heading states the supported Lua version.

## [Unreleased] — Lua 5.5

### Fixed

- `hecate.net` review fixes (TLS and buffered reader): `TlsStream` serialises drain and write under a mutex (records can no longer be reordered by a concurrent reader and writer), `is_closed` follows a cancelled write, a stalled session raises instead of spinning, `read` validates `max` and the native `read` clamps it to 16 KiB; `connect_tls` and `tls.connect`/`accept` validate arguments before connecting, reject inconsistent options (`tls_config` with `ca_pem`, `cert_pem` without `key_pem`) and name the missing `ca_pem` (OQ-41); `BufferedReader` validates the per-call limit, accepts a `limit` on `read_exact`, joins chunks once per read (linear instead of quadratic) and raises on a read after `close`; the native crate forbids `unsafe`, denies warnings and clippy, and drops the rustls `logging` feature (the `log` crate leaves `Cargo.lock`).
- `hecate.net`, `hecate.reactor`: `net.resolve` never returns an empty list (it raises `TransportError`), `connect`, `listen` and `bind_udp` validate the port before resolving, `pipe_listen` and `pipe_connect` raise `ArgumentError` for a Unix socket path longer than the platform limit, `Reactor:live_tasks` is renamed `live_coroutines` (glossary), glossary entries stream, back-pressure and half-close.

### Added

- ADR 0023 (multi-process serving) and ADR 0024 (TLS trust store, security reviewed) accepted by the owner on 2026-10-18; OQ-8, OQ-41 and OQ-44 resolved; the GC spike now includes an ORM-shaped workload (generational mode: typical slow step 2 to 3 times shorter, rare major collection 0.25 to 0.8 s); `rustls` updated to 0.23.46 (four advisories of 0.23.45, `cargo audit` clean); key elements of the upstream luv issue for TCP `reuseport` ([OQ-43](docs/spikes/OQ-8/luv-issue.md)).
- `hecate.net`: TLS trusts the operating system's store by default (`rustls-platform-verifier`, Proposed [ADR 0024](docs/adr/0024-tls-trust-store.md), owner decisions of 2026-10-18): `net.connect_tls(host, port)` works against a public server with no option, `ca_pem` adds trust anchors, `system_roots = false` trusts only `ca_pem`, verification still cannot be disabled, an unknown issuer says how to fix the trust store; 4 to 7 crates added per platform; a public-server test (`HECATE_NETWORK_TESTS=1`) runs in CI. Garbage collector mode: spike and OQ-44 ([report](docs/spikes/OQ-44-gc-mode.md)); OQ-43 updated with the upstream research.
- Multi-process serving (OQ-8): spike with measurements on Linux and, from CI, on macOS and Windows ([report](docs/spikes/OQ-8-multi-process.md), `docs/spikes/OQ-8/`), Proposed [ADR 0023](docs/adr/0023-multi-process-serving.md) (share-nothing workers; `reactor` mechanism, `kernel` policy; listening strategies `reuseport` on Linux and `round_robin` elsewhere, a shared listening socket measured and dropped; Linux never constrained by another platform), OQ-43 (TCP `SO_REUSEPORT` from Lua: luv sets it for UDP only, a four-line patch is verified), glossary entries primary, worker and listening strategy, the "Workers" section of concurrency.md, roadmap item for the `reactor` primitives.
- `hecate.net` review fixes: native TLS session failures always raise `TlsError`; `TlsStream:is_closed()` reflects a closed inner stream; a handshake that makes no progress raises instead of spinning; a closed `BufferedReader` raises instead of reporting a clean end of stream; `limit` and `max` arguments are validated; a poisoned `BufferedWriter` raises a fresh `NetworkError` with the original failure as `cause`. CI sets `HECATE_REQUIRE_NATIVE=1` so the TLS tests cannot be skipped silently.

- `hecate.net` (step 6): TLS over `rustls` (ring provider) bound through `mlua`, used sans-IO (ADR 0021): Rust crate `packages/net/native` (`Cargo.lock` committed), `net.tls` (`client_config`, `server_config`, `connect`, `accept`, `available`), `net.TlsStream` (implements `Stream`; `handshake`, `shutdown`, `alpn`, `server_name`, `version`, `peer_certificate`, `reader()`/`writer()`), `net.connect_tls` and `net.TlsError`. SNI, ALPN, mutual TLS, certificate verification always on (no switch; trust anchors passed as `ca_pem`, OQ-41), truncation without `close_notify` raises. Task `build-native` builds the module into `.hecate/rocks`. Loopback tests against a local test CA skip with a message when the module is not built.
- Documentation, owner decisions of 2026-10-13 on the OQ-11 questions recorded in ADR 0012 (status unchanged), OQ-11 and OQ-33 to OQ-38: route (a), earlier timeline (minimal `hecate.doc` and the reference generator pulled forward in the roadmap), brand kit, dependencies wanted, WebAssembly, reference generation by `---@class`. Content conventions (agent's choice, [documentation.md](docs/architecture/documentation.md)): the page title is the single `#` heading of the body, front matter `title` an optional label override, code samples included from tested files. `hecate.doc` displays the body heading and uses `title` for labels (`Page.heading`); the website pages follow and markdownlint no longer counts a front matter title as a heading. Spike OQ-39 ([report](docs/spikes/OQ-39-doc-dependencies.md): Markdown, highlighting, search, OpenAPI, WebAssembly) and proposed ADR 0022 (comrak, syntect, Pagefind, own OpenAPI rendering, Lua 5.5 in WebAssembly); no dependency added yet.
- `hecate.doc`: code reference generated from the LuaLS `--doc` JSON export (`reference`, `reference_site`, `luals`, `bin/reference.lua`, `build.lua --reference`, task `gen-reference`): pages for packages, classes, types and module functions with the nine sections of the reference template, `---@async` shown as "May suspend", tested examples included from `packages/<package>/examples/`, stable anchors, deterministic output, pages not committed; strict JSON decoder in `hecate.doc.internal.json` (OQ-40); annotation conventions in `docs/architecture/coding-standards.md`; `core`, `reactor` and `net` annotated so that their public functions appear in the export (behaviour-neutral: assignments instead of constructor entries, `function M.name` definitions, internal renames in `reactor`).
- `hecate.doc` (first slice, owner direction of 2026-10-13: route 2, VitePress-like features, Hecate brand kit; ADR 0012 keeps its status): own static site generator in Lua 5.5 with no third-party dependency. Markdown renderer (CommonMark subset, GFM tables, task lists, strikethrough, `::: note|tip|warning|danger` containers, escaping and a URL allow-list by default), front matter, Lua/JSON/shell/HTTP/diff highlighting, site model with locales (English fallback with a visible notice), sidebar and previous/next computation, edit link, last-updated dates, search index per locale, `build` library function and `packages/doc/bin/build.lua` runner, original theme on the brand-kit tokens (light/dark with toggle, top bar with logo, section links, search dialog, locale switch and repository link, sidebar, "On this page" outline, previous/next cards, copy buttons, responsive menus; STIX Two Text, Fira Sans, Fira Code). `website/site.lua`, a home page and the public glossary. Vendored fonts, brand files and one icon are recorded in `THIRD_PARTY_NOTICES`. Choices left open: OQ-33 to OQ-38.
- `hecate.net` (step 5): `PipeStream`, `PipeListener`, `net.connect_pipe` and `net.listen_pipe` over Unix-domain sockets (named pipes on Windows); `hecate.reactor`: `pipe_connect`, `pipe_listen`, `PipeStream`, `PipeListener`, reusing the TCP stream machinery. TLS remains.
- `hecate.net` (step 4): `UdpSocket` (`send_to`, `receive_from`, `local_address`, `close`) and `net.bind_udp` with host-name resolution; `hecate.reactor`: `udp_bind` and `UdpSocket`, suspending datagram I/O. A cancelled `receive_from` keeps the socket and loses no datagram; a cancelled `send_to` closes the socket. Failures raise `reactor.TransportError`.
- `hecate.net`: `net.resolve(host, options?)`, name resolution exposed on the network surface (delegates to `reactor.resolve`).
- `hecate.net` (step 3 of the roadmap item): `TcpStream` (implements `Stream`; `shutdown`, addresses, options, `reader()`/`writer()`), `TcpListener`, `net.connect` and `net.listen` with host-name resolution, over the reactor transport; per-operation deadlines through `reactor.deadline`. `hecate.reactor`: `resolve(host, options?)`, a suspending `getaddrinfo`. Design choices in OQ-32. Failures of TCP and name resolution raise `reactor.TransportError`, a `core.NetworkError` (`catch` on `NetworkError` works; `IoError` stays for fs and processes).
- `hecate.net` (step 1 of the roadmap item; not complete): `BufferedReader` (`read_line`, `read_until`, `read_exact`, `read_some`, limit on record length) and `BufferedWriter` (`write`, `flush`, capacity, poisoned after a failed flush) over any object implementing the `Stream` interface, and `EndOfStreamError`. Partial reads and writes never leak. `TcpStream` and `TcpListener` are blocked on OQ-28 (the luv confinement of ADR 0002 requires transport primitives in `reactor`); design choices of the buffered layer are recorded in OQ-29. UDP, DNS, Unix sockets and TLS remain.
- `hecate.reactor` (transport step, OQ-28 option a): `tcp_connect`, `tcp_listen`, `TcpStream` (`read`, `write`, `shutdown`, `close`, `peer_address`, `local_address`, `set_nodelay`, `set_keepalive`, `<close>`-able) and `TcpListener` (`accept`, `close`, `local_address`) as suspending calls, so `hecate.net` never requires luv. Cancellation closes or abandons safely without leaking handles or callbacks; failures raise `IoError` with `context.errno`. Every real-clock run now guards against `SIGPIPE`. Numeric addresses only; UDP, DNS and pipes remain. Design questions are recorded in OQ-30 and OQ-31; OQ-28 is resolved.
- `hecate.reactor` (step 4 of the roadmap item): `detach`, `fs` (`read_file`, `write_file`, `stat`, `remove`, `mkdir`, `rmdir`, `list`), `wait_signal` and `run_process` as suspending calls over libuv, and `IoError`. They need the real clock. Design questions are recorded in OQ-26. `offload`, worker primitives and the website reference remain.
- `hecate.reactor` (step 2 of the roadmap item): `Channel(capacity)` (rendezvous or buffered, FIFO, `close`), `ChannelOperation` (`Channel:send_op`, `Channel:receive_op`) accepted by `select` next to futures, `Semaphore`, `Mutex`, `Monitor` and `Condition` with `<close>`-able `Permit`s. All are cancellation-safe (cancelled waiters are withdrawn and never swallow a permit, value or signal) and FIFO fair. `ClosedChannelError` is new in `hecate.core`. Design questions are recorded in OQ-25.
- `hecate.reactor` (Phase 1, step 1 of the roadmap item; not complete): the `Reactor` scheduler over luv with a real clock and a deterministic virtual clock, `Future` (`value`, `cancel`, `done`, `state`), `fork`, `join`, `select`, `sleep`, `scope` and `deadline` with structured concurrency and cooperative, level-triggered cancellation that runs `<close>` handlers, `Instant`, deadlock detection, and `NonYieldableContextError` (new in `hecate.core`) for suspending calls outside a managed coroutine or inside a non-yieldable C boundary. The test task now puts every package source tree on the path so packages can require their dependencies. Design questions OQ-22 to OQ-24 are recorded. Channels, synchronisation primitives, `detach`, `offload`, signals, processes and file-system operations remain.
- `hecate.core` (Phase 1): `class`, `trait`, `interface`, `finalise` (single inheritance, flat trait composition with exclusion and aliasing, conformance checked at finalisation, inherited metamethods including `__close`), introspection (`name`, `superclass`, `traits`, `interfaces`, `is_instance_of`, `implements`, `origin`), the `Error` hierarchy with cause chaining, stable codes and optional tracebacks, `enumeration`, `value_class` and `hecate.core.compat`. The `fallback_provides` class option declares the members an `__index` fallback provides. Design questions OQ-19 to OQ-21 are resolved. Glossary: finalisation, conformance, superclass, enumeration, cause chain; the term "parent" is replaced by "superclass" throughout.
- Monorepo tooling: task runner `tools/run.lua` (`check-package-structure`, `check-versions`, `check-rockspecs`, `gen-rockspecs`, `lint`, `typecheck`, `test`, `format`/`format-check` as no-ops), bootstrap test harness `tools/harness/` (ADR 0008), `.luarc.json`, per-package `scm-1` rockspecs and `tests/` skeletons.
