# Spikes

Time-boxed research reports answering entries of [open-questions.md](../open-questions.md).
One file per spike: `<OQ-id>-<slug>.md` with question, method, findings (versions and
platforms), recommendation and remaining risks. Use the `/spike` command.

Spike reports and scripts are history: they keep the vocabulary and the names of their time (HTTP "headers", "task",
"handler", modules that were removed since). Only a factual contradiction with a decided name or status is corrected,
with a dated note; the measurements are never rewritten.
